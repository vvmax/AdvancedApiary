# Расчёт эффективности Advanced Apiary 0.6.1

Расчёт по коду аддона, при 20 TPS, постоянно работающих матках и свободном выходе.
Это математическое ожидание, а не гарантия количества предметов на коротком отрезке.
Конкретные породы, скорость генома и целевой продукт пользователя неизвестны.

## Почему семь параллельных модулей мало производят

Без ускорения цикл длится 550 тиков (27,5 с). Семь параллельных модулей дают
8 независимых попыток на матку за цикл. При эффективном шансе 15% одна матка
производит в среднем 1,2 предмета за цикл, а шесть — 7,2 предмета.
Это всего 15,71 предмета/минуту для одной строки продукта размером 1 предмет.
Например, базовый шанс 30% и генетическая скорость 0,5 дают эффективный шанс 15%.
При вероятности 15% шанс не получить этот продукт из восьми попыток одной матки
составляет 0,85^8 = 27,25%. Необходимо оценивать длинные интервалы.

Семь параллельных модулей проверены отдельно: при гарантированном шансе каждая
матка получает ровно 8 результатов каждого продукта за 550 тиков.
Длинная проверка шанса 25% использует 80 000 независимых попыток с фиксированным seed.

## Практический набор: сад и обычная продукция

**1 внутренний сад + 3 ускорения + 4 параллельного производства.**

- Все восемь слотов заняты; внешние условия должны подходить маткам.
- Цикл floor(550/4) = 137 тиков = 6,85 с.
- Пять попыток на матку за цикл, 30 попыток на шесть маток.
- При эффективном шансе 15%: 39,42 предмета/минуту, в 2,51 раза больше набора с семью параллельными.
- Набор с 3 ускорениями, 3 параллельными и 1 продуктивностью даёт тот же результат
  для обычного продукта, пока шанс не насыщен. Четыре параллельных лучше при насыщении.
- Это не компенсирует ночь, дождь, неподходящий климат и закрытое небо.

Если нужен свет для работы днём и ночью:
**1 сад + 1 освещение + 3 ускорения + 3 параллельных**.
При том же шансе 15%: 31,53 предмета/минуту при непрерывной работе.
Это выгоднее 39,42/мин при работе только половину суток. Реальный выигрыш зависит
от длительности простоев, генов и погодных условий.

Если дополнительно нужна защита от дождя:
**1 сад + 1 освещение + 1 защита от дождя + 3 ускорения + 2 параллельных**.
При шансе 15%: 23,65 предмета/минуту при непрерывной работе.
Для ночных видов вместо освещения используется затемнение; вид с соответствующими
генами может вообще не нуждаться в модуле. Климат и небо резервируются аналогично.

## Если нужны именно редкие специальные продукты

Для одного специального продукта с эффективным шансом 5%, семи свободных слотов
и подходящей среды перебор даёт:
**1 сад + 2 ускорения + 2 параллельных + 1 специальностей + 2 фокусировки**.

Цикл 183 тика, три попытки, шанс специального продукта 5% × 1,5 × 3 = 22,5%.
Шесть маток дают в среднем **26,56 предмета/мин** этого специального продукта.
Но фокусировка снижает обычную продукцию! Это максимум именно выбранной
специальности при указанном шансе, а не максимум всех ресурсов одновременно.
Для других шансов, нескольких разных продуктов и других геномов оптимум меняется.

## Формула и калькулятор

Для каждой строки продукта:

```
T = max(20, floor(cycleTicks / (1 + ускорение)))
Q = базовый шанс × скорость генома × productionMultiplier
M = 1 + 0,25 × продуктивность
Обычный шанс = min(1, Q × M / (1 + фокусировка))
Специальный шанс = min(1, Q × M × (1 + 0,5 × специальности) × (1 + фокусировка))
Предметов/мин = число маток × 1200/T × (1 + параллельность) × шанс × размер результата
```

Модули не увеличивают врождённую скорость генома. Медленные гены уменьшают
выход даже при одинаковом виде. При нескольких матках с разными геномами нужно
посчитать каждую отдельно и сложить, учитывая один общий набор модулей.
Для суммы разных продуктов также нужно суммировать их ожидания; максимум одного
специального продукта может оказаться невыгоден для всего набора ресурсов.

Калькулятор перебирает все комбинации ускорения, параллельности, продуктивности,
специальностей и фокусировки для одного выбранного продукта:

```
python tools/optimize_modules.py --slots 7 --chance 0.15
python tools/optimize_modules.py --slots 7 --chance 0.05 --specialty
python tools/optimize_modules.py --slots 6 --chance 0.15 --queens 6
```

Из восьми слотов заранее вычесть сад, необходимые модули условий и автоэкспорт.
Извлечение трубой не требует модуля экспорта. Без сада при включённом ИИ можно
использовать внешние растения, освободив слот. Остановка производства и заполненный
выход снижают реальный выход; расчёт предполагает, что продукция успевает выводиться.


## Когда нужна продуктивность

Каждая карта прибавляет 0,25 к множителю шансов: 1; 1,25; 1,5; 1,75 и т.д.
Относительный выигрыш следующей карты равен 0,25/(1+0,25×P), пока шанс не насыщен.
Для параллельности относительный выигрыш следующей карты равен 1/(1+R).
При R=3 и P=0 оба выигрыша составляют 25%. Поэтому с семью производственными
слотами набор 3 ускорения + 3 параллельных + 1 продуктивности равноценен набору
3 ускорения + 4 параллельных для обычного продукта с эффективным шансом до 80%.
При более высоком шансе продуктивность упирается в потолок 100%.

Если сад не нужен (ИИ включён, цветы снаружи) и среда подходит, свободны все
8 слотов. Для эффективного шанса обычного продукта 15% оптимум:
**3 ускорения + 4 параллельных + 1 продуктивности** — 49,27 предмета/мин
от шести маток для одной строки продукта с размером результата 1.
Для сравнения 4 ускорения + 4 параллельных дают 49,09 предмета/мин.
Небольшое преимущество первого набора обусловлено целочисленным округлением цикла.
При эффективном шансе 100% продуктивность бесполезна, поскольку шанс уже насыщен.
Утверждение, что максимальный набор всегда обходится без продуктивности, неверно:
нужно учитывать свободные слоты, эффективные шансы и целевой продукт.
